# Multi-Agent System with LangGraph

A two-agent pipeline built with LangGraph and Groq.

## What it does
- Researcher agent searches the web using DuckDuckGo
- Writer agent uses Llama 3 to generate a blog post from the research

## Setup
1. Open the notebook in Google Colab
2. Add your Groq API key from console.groq.com
3. Run all cells
